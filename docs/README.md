# /docs — Project knowledge

This directory is the durable home for everything CHEESE figures out about this project. All files are committed; nothing here lives in app-local storage.

| File | What it answers |
|---|---|
| Project_Brief.md | What are we building, end to end? |
| Personas.md | Who is each piece for? |
| User_Stories.md | What value does each piece deliver? |
| Orchestration_Plan.md | In what order are we building it, and why? |
| Activity.md | What context-shaping actions has CHEESE taken in this project? |
| slices/*.md | What happened in each slice, and what did we learn? |
| memory/*.md | Project rules and gotchas captured ad-hoc. |
| plans/*.md | Plan-mode artifacts mirrored from `~/.claude/plans/`. |

When in doubt, read these in order: README → Project_Brief → Orchestration_Plan → the relevant slice file.

> Generated by CHEESE on first orchestration. Hand-edit freely; CHEESE will not overwrite this file once it exists.
